# Demo inventory

This build is in testing mode.

- Real uploaded vehicle photos always take priority.
- Cars without an approved real photo receive a rotating reference image and are labeled "Reference image".
- If the production database has zero public motorcycles, six clearly labeled demo/test motorcycles are shown automatically. They do not alter MySQL and are not real sale offers.
- As soon as real approved motorcycle inventory exists, the demo motorcycle fallback disappears automatically.
- Homepage category cards now link to Cars, Motorcycles, Vehicle Sourcing and Export Support.
